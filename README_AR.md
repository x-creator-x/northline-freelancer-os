# NORTHLINE Freelancer OS — النسخة الأولية 1.0

هذه نسخة تشغيلية أولية responsive تعمل كتطبيق ويب تقدمي (PWA)، ومهيأة ليتم تغليفها كتطبيق iOS وAndroid باستخدام Capacitor من نفس قاعدة الواجهة.

## التشغيل محليًا
- افتح `index.html` مباشرة لمعاينة الواجهة الأساسية.
- لتفعيل التثبيت والعمل دون اتصال، شغّل المجلد عبر خادم محلي أو ارفع الملفات إلى استضافة HTTPS.
- يمكن استخدام `npx serve .` بعد تثبيت Node.js.

## بناء تطبيقات iOS وAndroid
1. ثبّت Node.js وXcode (لـ iOS) أو Android Studio (لـ Android).
2. من داخل المجلد نفّذ `npm install`.
3. نفّذ `npx cap add ios` و/أو `npx cap add android` مرة واحدة.
4. نفّذ `npx cap sync` ثم `npx cap open ios` أو `npx cap open android`.
5. أكمل إعدادات التوقيع والحسابات المطلوبة داخل Xcode / Android Studio قبل النشر.

## الوظائف الموجودة في ملف Excel والتي تم نقلها إلى هذه النسخة
- لوحة التحكم: دخل الشهر، المصروفات، صافي الربح، هامش الربح، هدف الشهر، المستحقات، المشاريع النشطة والمتأخرة، توزيع صافي الربح والتنبيهات والرسم المالي.
- العملاء: حالة العميل، مصدره، موقعه، وسيلة التواصل، إجمالي قيمة المشاريع والتحصيل والمتبقي والتصنيف التلقائي VIP / متكرر / جديد.
- المشاريع: العميل والخدمة والتواريخ والعملة والسعر والحالة والدفعات والمتبقي وحالة الدفع والأيام المتبقية والتنبيه وساعات العمل وربح الساعة.
- الدفعات: ربط الدفعة بالمشروع والعميل، عملة المشروع، طريقة الدفع، والتحويل إلى العملة الأساسية.
- المصروفات: التاريخ والفئة والوصف والمبلغ والملاحظات.
- ساعات العمل: التاريخ والمشروع والساعات ووصف الإنجاز وربطها بالعميل والمشروع.
- حاسبة التسعير: الدخل الصافي المستهدف، المصروفات الثابتة، الضرائب والطوارئ، أيام وساعات العمل، الحد الأدنى لسعر الساعة والسعر المثالي، التعقيد والتعديلات والرسوم وثلاث باقات.
- مولد الرسائل: عرض سعر، تذكير بالدفع، تسليم المشروع، طلب تقييم.
- الإعدادات: العملة الأساسية، الهدف، نسب التوزيع، VIP، الدفعة المقدمة، جولات التعديل، الاسم وتفاصيل الدفع وأسعار الصرف.

## ملاحظات مهمة قبل الإطلاق التجاري
- البيانات محفوظة محليًا في المتصفح على الجهاز الحالي؛ النسخ الاحتياطي JSON متاح من الشريط العلوي والإعدادات.
- هذه نسخة MVP تجريبية وليست بعد نظامًا سحابيًا متعدد المستخدمين. لم يتم إعداد تسجيل دخول أو مزامنة بين الأجهزة أو بوابة دفع.
- بيانات العرض داخل التطبيق تجريبية ومأخوذة لتوضيح الاستخدام؛ احذفها أو استبدلها ببياناتك.
- أسعار الصرف افتراضية تقريبية ويجب تحديثها يدويًا.
- أُبقيت أسماء الحالات والحقول والمعادلات الوظيفية الأساسية وفق ملف NORTHLINE_Freelancer_OS.xlsx، مع تحويل التجربة إلى واجهة عربية حديثة.
